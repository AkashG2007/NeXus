# CVCC Simulator

This project is a CVCC Simulator with a Next.js frontend and a Python backend. It features a Leaflet map engine.

## Project Structure

- `/frontend` - Next.js frontend application (React, Tailwind CSS, Leaflet)
- `/backend` - Python backend (Digital twin simulation environment)

## Getting Started

### Frontend
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

### Backend
1. Navigate to `backend/`
2. Set up a virtual environment and activate it.
3. Install requirements: `pip install -r requirements.txt`
4. Run the backend: `python main.py`
